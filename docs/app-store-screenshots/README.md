# App Store screenshots

Capture these frames on a physical iPhone (or Simulator) while signed in with real group data:

1. **Home** — today’s motion + selected group  
2. **Leaderboard** — category leaders / rankings  
3. **Group** — members list  
4. **Profile** — progress ring  
5. **Optional** — Notification Center or Settings → Notifications  

## How to capture (iPhone)
1. Open each screen  
2. Press **Side button + Volume Up**  
3. Airdrop or Finder sync to Mac  
4. Upload into App Store Connect → Got Motion → **1.0 Prepare for Submission** → Screenshots  

## Sizes Apple wants
Use the slots ASC shows (commonly **6.7"** and **6.1"** iPhone). One set of portrait screenshots is enough to start; you can duplicate into both slots if dimensions match.

Drop exported PNGs in this folder for safekeeping (optional).
